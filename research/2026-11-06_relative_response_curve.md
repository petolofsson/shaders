# Relative-response brightness model

The preceding ordered curve adds a bounded amount of linear luminance, which behaves like a small pedestal and can reduce relative contrast in cool materials. This screen tests a different construction: in the shadow range make the correction proportional to output Y, so its *relative* response can remain unchanged or increase instead of fading an additive offset. The result illustrates the tradeoff but is **not a candidate for adoption**: the selected deep-shelf response barely improves, while brighter cool materials receive a broader lift.

For grade-input Y `x` and existing output Y `y`, use `y' = y * (1 + 0.08*smoothstep(0.003864,0.010,y)*(1-smoothstep(0.08,0.30,y))*smoothstep(0.0005,0.003,x))`. The 0.003864 pivot is still fitted to the original GZW shelf and 8% is an exploratory coefficient. For a fixed input gate, below Y=0.08 the gain is nondecreasing with y; therefore the fixed-context relative log slope is at least one wherever differentiable. The correction is nonnegative and nondecreasing in input gate, so coincident input/output scalar ordering is preserved if the complete mapping remains increasing in y. The fade begins above the target shadows and necessarily changes that relative-slope behavior. A common RGB headroom cap is needed and, as [previously shown](2026-11-06_ordered_brightness_headroom.md), invalidates a general cross-color ordering guarantee. The same input-black and clipping caveats apply.

The screenshot proxy combines the output-color model from the previous study with this brightness function, using independent 8-bit output and diagnostic-input stills. The separate CPU numerical check uses the actual sparse [same-update float pairs](2026-11-06_shadow_float_detail.md) and applies both proposed headroom caps. Neither is a compiled candidate. For the four-pixel float patches, input-signed mean output Y gaps change shelf 0.0003633→0.0003717, metal 0.0003712→0.0003809, blue wall 0.0023282→0.0025145, and cool window 0.0097743→0.0104483. Reversal counts remain 0/0/0/6 on these samples. These overlapping, input-selected pairs are descriptive, not independent observations or quality scores; the brighter wall/window changes accompany mean Y increases of 0.00511 and 0.00490, respectively, while the shelf mean increase is 0.0000103. The small shelf change does not establish the requested visible shadow improvement.

In the larger selected screenshot rectangles, the four-pixel signed log-Y gaps are current→proxy 0.11596→0.11642 shelf, 0.13701→0.14519 metal, 0.07589→0.07561 blue wall, and 0.14997→0.15411 cool window. The shelf L quartile gap changes 2.661→2.673; its source-selected L 12–35 median is 16.073→16.035. Other material levels and neutral/color costs remain. Quantization, masks and independent captures limit these figures. This is one design example, not a width/strength sweep or an assertion that any proportional gain is unsuitable.

The physical issue is that improving relative gradients in the dimmest region while rejoining identity later moves compression or brightness changes elsewhere. This example preserves more relative response higher up by carrying an 8% gain into brighter tones, but that does not solve the weak shelf effect or guarantee unobtrusive lighting. The earlier black/neutral, saturated-headroom, source-color, real warm/red-black, temporal and visual issues remain.
