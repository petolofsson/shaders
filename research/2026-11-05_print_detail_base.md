# Detail-preserving print-base screen — 2026-11-05

**Decision: reject this isolated candidate.** It does not produce a clear visual improvement in the selected native dark-material crops and lowers measured neighboring-shade contrast. No production shader, profile, configuration or rating changed.

The prototype reuses the adopted 25-tap source tonal base already computed in `ApplyTonal`. In the shadow range it changes the print power-toe factor to use the shared base for print density while carrying pixel variations through as a proportional gain. Concretely it multiplies the existing `pow(lin,1.15)` result by `exp2(0.15 * (illumination_log-native_log) * shadow_weight)`; the weight fades from full below linear Y=0.10 to zero at Y=0.25. This is an isolated approximation to a locally shared print gain, not a physical illumination model or a new resource/pass. Later print color/shoulder functions remain present. The shared base can vary between pixels, so unit relative-detail response is not guaranteed across an actual image.

The underlying assumption was flawed for the current toe: locally, `x^1.15` **expands relative log differences** by 1.15 even while darkening absolute output. Replacing its per-pixel gain with a locally shared gain tends toward unit relative response and can reduce relative separation. Fixed source-selected neighboring shade pairs support this in these images: mean signed output gaps at 1/4/16-pixel offsets change from 0.100760/0.115991/0.126915 to 0.093813/0.108082/0.118694 stops on the GZW shelf, and from 0.113594/0.136975/0.156600 to 0.110018/0.131980/0.150219 on Arc dark metal. These metrics do not by themselves establish perceptual quality. Source-selected pairs and masks use the previous tonal-material analysis helper.

Four current-profile isolated candidate/repeat pairs cover GZW dark shelf, Arc trader interior, Arc emitter, and vivid Arc content processed by the GZW profile. All four candidate pairs are pixel-exact after masking the intentional marker; all eight private GPU processes reported zero dropped/delayed frames. Candidate versus current maximum differences are 2/2/2/4 codes respectively, with 400/1,078/129/9,962 pixels over one code. These counts do not establish visibility. Current and candidate native crops show no clear improvement in the target regions. The vivid scene is not a third game. Capture artifacts and source/profile/config/grade hashes are in `captures/print_base_20261105/report.json`; current baselines are the prior November 4 current-profile captures and verified November 3 Arc emitter capture. Snapshot identities and source/profile epochs must match before reuse.

This is an early static rejection. The candidate did not receive independent numerical GPU, zero, gradient, edge, temporal, performance or actual-config adoption validation; there is no claim that it is stable or that its test is a universal judgment of detail-preserving print. No gradient capture or further parameter sweep was performed after the target failed. Native review crops and scripts remain ignored local artifacts in `captures/print_base_20261105/`.
