# Same-update floating-point shadow observations

The user asked whether higher precision could clarify the shadow findings. A private headless diagnostic now samples grade input and a pre-dither clone of the current production grade calculation in the **same GPU update**, stores them in RGBA32F, and encodes six 24-bit values per sample for readback. This removes the ordinary 8-bit screenshot quantization from these observations; it does not change the game's input or swapchain precision. For these sparse samples, simulated 16-bit sRGB quantization retained the same pair-order classifications as the float readback, while simulated 8-bit quantization changed some classifications. This supports using higher precision for measurement; it does not establish that a 16-bit production pipeline would yield a visible improvement or that prior screenshot-based candidate reversals are shader defects.

## Diagnostic and validation scope

The test captures a 16×16 grid at native pixel centers in each previously selected GZW shelf and blue-wall and Arc metal and cool-window rectangle. Immediately before the ordinary grade color transform, an extra diagnostic pass reads post-inverse input and evaluates a mechanically cloned production `ColorTransformPS` through the look stage, stopping before output dither and encoding. The ordinary grade transform and later history passes still execute; a final pass writes the encoded diagnostic after those passes. The clone and grade input are sampled in the same diagnostic invocation and update. It is a **clone**, not simultaneous direct readback of the ordinary BackBuffer write; the extra pass could affect runtime conditions. Normalized source identity, cloned-body hash, configs, source/clip/image identities and initial/final production hashes are recorded in `captures/shadow_float_pairs_20261106/report.json`.

The readback encodes the interval [0,0.25] with a nominal step of about 1.49e-8 per channel. Samples with any channel at the encoding ceiling are excluded from comparisons: 15 metal and 22 cool-window samples, leaving 256 shelf, 241 metal, 256 wall and 234 window. Values outside the encoding range cannot be reconstructed. Each static grid has an identical float-readback repeat at encoded precision; eight fresh private headless processes report zero dropped/delayed frames. Settling was 20 seconds; that and exact still repeats do not establish temporal convergence or moving-game stability.

As an independent sanity check, encoded grade-input samples were compared with the previously captured 8-bit diagnostic input screenshot at matching pixel centers: maximum discrepancies were 0.062–0.147 8-bit code over the four valid sample sets. The float output, encoded to sRGB, differed from separately captured ordinary full screenshots by up to 0.995–1.105 codes, with mean differences 0.329–0.342 codes; ordinary output includes dither and the comparisons are separate captures. These are useful sanity checks, not an exact same-update equivalence proof. The first diagnostic failed its required activity-marker check; the failure image and logs are retained. An initial grid sampled fractional positions; its outputs and report are retained separately under `interpolated/` and excluded from the centered-grid table below.

## Precision comparison

For horizontal and vertical adjacent grid samples, include a pair if both samples are valid, both grade-input Y values exceed 0.0005, and their input-Y difference exceeds 0.00001. These are **coarse grid-neighbor pairs** (roughly 10–29 source pixels apart depending on rectangle), not the earlier 1- or 4-pixel source-selected material pairs. Pairs overlap; source and output are different stages, so a reversal is descriptive rather than automatically a defect. Quantization here is simulated by rounding the float output to 8- or 16-bit sRGB and decoding again, with no dither.

Rounding changes can both create and remove a reversal, so changed classifications need not equal the net difference. The simulated 16-bit result retained the float classifications in this sample, not a universal guarantee. Mean signed output Y gaps for float versus simulated 8-bit were 0.00054957/0.00054954 shelf, 0.00222596/0.00220872 metal, 0.00645292/0.00650174 wall and 0.01484950/0.01485715 window. These linear-Y averages are not perceptual scores and do not demonstrate that all fine detail survives the chain. Exact selection, data and calculations are in `analysis.py` and `analysis.json` in the capture directory.

## Research model on captured pairs

An independent CPU calculation applies the [ordered-brightness and grade-input color model](2026-11-06_ordered_shadow_design.md), with the separately researched common-factor color and RGB-gain headroom caps, to these same-update float pairs. This does **not** execute the candidate on the GPU. For shelf, 140/256 valid samples change after simulated 8-bit sRGB output quantization versus 255/256 after simulated 16-bit; metal is 221/241 versus 241/241, wall 254/256 versus 256/256, and window 212/234 versus 234/234. Maximum 8-bit change is two codes in each region. These counts are sensitive to quantization boundaries and do not measure visual quality; a 16-bit output has more distinguishable codes by construction. Neither headroom cap engaged in these valid samples, which does not invalidate the synthetic saturated-face counterexamples. CPU scripts and exact data are in `candidate_cpu.py` and `candidate_cpu.json`.

As a coarse color cross-check, use the separate 8-bit source-only screenshot to select valid grid samples with source Oklab L 12–35 and split them by source b quartiles. The mean output a/b group distance ×100 changes 0.290→0.327 on shelf (194 samples), 1.559→1.632 on metal (237), 0.128→0.121 on wall (30), and 1.853→1.936 on window (75). The source groups may differ in lightness; their small sparse populations, source screenshot quantization, and independent capture constrain interpretation. These findings are consistent with the directions of the earlier crop proxies, but do not establish visibility, intentional color fidelity, or a compiled-candidate result. For example, selected metal median L also rises 17.724→18.095 in this CPU model.

On the same coarse grade-input-signed pairs as the precision table, the CPU model changes mean linear-Y output gaps 0.000550→0.000623 shelf, 0.002226→0.002398 metal, 0.006453→0.006480 wall, and 0.014850→0.014860 window; reversal counts remain 0, 3, 1 and 2. These sparse longer-distance samples do not replicate the earlier four-pixel source-selected test, where the wall and window gaps decreased. Different populations, scales, input references and quantization prevent treating either result as a contradiction or a general ordering guarantee.

The result supports further use of high-precision same-update diagnostics and confirms that 8-bit screenshot quantization affects some fine comparisons. It does not resolve the candidate's cool-material, source-neutral or ordering tradeoffs; change source precision; validate a full-frame 16-bit game output; or establish a GPU candidate, motion, active-config, performance or visual acceptance. Production shaders, profiles, configurations and ratings are unchanged.
